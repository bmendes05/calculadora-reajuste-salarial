# Calculadora de Reajuste Salarial em Python

## Sobre o projeto

Este projeto consiste em um programa desenvolvido em Python para calcular o reajuste salarial de um funcionário.

O usuário informa o salário atual, e o programa calcula automaticamente um aumento de 15%, apresentando o valor do salário atualizado.

O projeto foi desenvolvido como exercício prático durante meus estudos em Análise e Desenvolvimento de Sistemas (ADS).

## Funcionalidades

- Receber o salário atual do funcionário.
- Calcular o aumento de 15%.
- Apresentar o salário original.
- Exibir o novo salário com duas casas decimais.

## Tecnologias utilizadas

- Python 3

## Conceitos aplicados

- Entrada de dados com `input()`.
- Conversão de valores utilizando `float()`.
- Operações matemáticas.
- Cálculo de porcentagem.
- Exibição e formatação de resultados com `print()` e `format()`.

## Como executar

1. Tenha o Python instalado no computador.
2. Baixe o arquivo `calculadora.py`.
3. Abra o terminal na pasta do projeto.
4. Execute o comando:

```bash
python calculadora.py
```

## Exemplo de execução

**Entrada:**
- Salário atual: R$ 2.000,00

**Resultado:**
- Salário original: R$ 2.000,00
- Aumento: 15%
- Novo salário: R$ 2.300,00

## Objetivo

Praticar os fundamentos da programação em Python, desenvolvendo a lógica de programação e aplicando operações matemáticas em uma situação do cotidiano.
